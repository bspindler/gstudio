# Bundled fonts (GStudio shelf page)

Downloaded 2026-11-11 so the shelf page makes no requests to Google's servers. These are Google Fonts' latin and latin-ext woff2 subsets, unchanged. Both fonts are under the SIL Open Font License 1.1 with no Reserved Font Name, and the license texts are next to the files. `npm run dev` serves them at `/_site/fonts/`.
